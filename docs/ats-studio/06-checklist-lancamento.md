# Checklist de lancamento

## Antes do lancamento

- Cliente aprovou preview final por escrito
- Pagamento final recebido
- Dominio confirmado
- Acessos DNS disponiveis
- Textos finais aprovados
- Imagens finais aprovadas
- Contactos revistos
- Politicas legais inseridas

## Tecnico

- Build sem erros
- Site responsive
- Links internos funcionam
- Links externos funcionam
- Formularios funcionam
- Emails chegam ao destinatario correto
- Pagina 404 existe
- Favicon configurado
- Open Graph configurado
- Metadata por pagina
- Sitemap, se aplicavel
- Robots.txt, se aplicavel
- SSL ativo

## SEO basico

- Title tag
- Meta description
- H1 unico por pagina
- Hierarquia de headings
- Alt text em imagens importantes
- URLs legiveis
- Performance aceitavel

## Analytics e tracking

- Google Analytics, se incluido
- Google Search Console, se incluido
- Pixel Meta, se incluido
- Eventos principais, se incluidos

## Dominio

- DNS configurado
- WWW e dominio raiz funcionam
- Redirects configurados
- Site antigo protegido ou arquivado

## Depois do lancamento

- Testar site final
- Testar formulario final
- Enviar link final ao cliente
- Enviar guia de entrega e manutencao
- Propor manutencao
- Guardar projeto no portfolio, se permitido
