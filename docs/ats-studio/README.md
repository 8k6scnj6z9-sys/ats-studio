# ATS Studio - Kit de documentos comerciais

Este dossier contem modelos para gerir projetos da ATS Studio desde o primeiro contacto ate a entrega final.

## Documentos

1. `00-processo-comercial.md` - visao geral do processo completo
2. `01-questionario-briefing.md` - briefing para enviar ao cliente
3. `02-template-proposta.md` - proposta comercial
4. `03-termos-contrato-servicos.md` - termos base de servico
5. `04-checklist-conteudos-cliente.md` - materiais a pedir ao cliente
6. `05-email-preview-feedback.md` - emails para preview e revisoes
7. `06-checklist-lancamento.md` - checklist antes e depois do launch
8. `07-guia-entrega-final.md` - guia de entrega e manutencao
9. `08-planos-manutencao.md` - planos mensais
10. `09-pacotes-servicos.md` - pacotes comerciais
11. `10-proposta-email-inicial.md` - emails comerciais iniciais
12. `11-guia-preview-vercel.md` - como enviar previews ao cliente
13. `12-guia-dominio-email-hosting.md` - guia de dominio, email e hosting

## Como usar

Duplicar o documento necessario, substituir campos entre `[ ]` e adaptar ao cliente.

Campos comuns:

- `[Nome]`
- `[Nome do cliente]`
- `[Nome do projeto]`
- `[Data]`
- `[Valor]`
- `[LINK DE PREVIEW]`
- `[URL]`

## Nota importante

O documento de termos/contrato e um modelo operacional. Antes de ser usado como contrato formal, deve ser revisto por um advogado.
