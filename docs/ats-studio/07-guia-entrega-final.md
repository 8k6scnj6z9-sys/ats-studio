## Como este site pode ser editado

Escolher uma das opcoes abaixo antes de enviar ao cliente.

### Opcao A - Site sem CMS

Este website foi desenvolvido em codigo e nao tem area de edicao para o cliente.

Isto significa que o cliente nao deve tentar editar codigo, ficheiros ou configuracoes tecnicas. Para alterar textos, imagens, paginas, horarios, precos ou seccoes, deve enviar o pedido a ATS Studio.

Fluxo recomendado:

1. Cliente envia pedido de alteracao
2. ATS Studio confirma escopo/prazo
3. ATS Studio faz a alteracao em codigo
4. Cliente revê a preview
5. ATS Studio publica a versao final

### Opcao B - Site com CMS

Este website inclui uma area editavel para os conteudos definidos no projeto.

O cliente pode editar apenas os campos preparados para esse efeito, como textos, artigos, imagens ou servicos. Alteracoes de layout, novas seccoes e funcionalidades devem ser pedidas a ATS Studio.

### Opcao C - Plataforma editavel

Este website foi criado numa plataforma editavel. O cliente pode alterar conteudos conforme as permissoes e limites da plataforma.

Alteracoes estruturais ou tecnicas devem continuar a ser feitas com apoio da ATS Studio.

## Como pedir alteracoes

Para pedir uma alteracao, enviar email com:

- Pagina onde esta o problema
- O que deve mudar
- Texto/imagem final a usar
- Prioridade

Exemplo:

```text
Pagina: Servicos
Alteracao: trocar o texto do servico X
Novo texto: [...]
Prioridade: normal
```

## Cuidados

Evitar:

- Alterar DNS sem avisar
- Instalar plugins sem necessidade
- Usar imagens muito pesadas
- Partilhar acessos sem controlo
- Editar codigo diretamente
