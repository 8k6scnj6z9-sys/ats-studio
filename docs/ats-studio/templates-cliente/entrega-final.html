03 / Edição

Como pedir alterações

Este website foi desenvolvido em código e não tem área de edição para o cliente, salvo indicação contrária no escopo.

Para alterar textos, imagens, páginas, horários, preços ou secções, o cliente deve enviar o pedido à ATS Studio.

1Cliente envia pedido de alteração.
2ATS Studio confirma escopo e prazo.
3ATS Studio faz a alteração e envia preview.
4Cliente aprova e a alteração é publicada.

Se o projeto incluir CMS, o cliente pode editar apenas os campos preparados para esse efeito. Layouts, novas secções e funcionalidades continuam a ser tratados pela ATS Studio.

04 / Cuidados

Evitar

  • Alterar DNS sem avisar.
  • Partilhar acessos sem controlo.
  • Usar imagens muito pesadas.
  • Editar código diretamente.
