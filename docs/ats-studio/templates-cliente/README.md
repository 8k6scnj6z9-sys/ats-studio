# Templates visuais para cliente

Estes ficheiros sao templates HTML prontos para editar e exportar para PDF.

## Templates incluidos

- `orcamento-proposta.html`
- `contrato-termos.html`
- `briefing-cliente.html`
- `entrega-final.html`
- `assinatura-email-ats-studio.html`
- `assinatura-email-ats-studio.txt`
- `ats-document.css`

## Como usar

1. Duplicar o ficheiro pretendido.
2. Trocar campos entre `[ ]`.
3. Abrir o HTML no browser.
4. Usar `Imprimir` / `Guardar como PDF`.

## Campos comuns

- `[Nome do cliente]`
- `[Nome do projeto]`
- `[Data]`
- `[Valor]`
- `[URL final]`
- `[Nome legal do cliente]`

## Nota sobre contrato

O template `contrato-termos.html` e uma base visual e operacional. Antes de ser usado como contrato juridico, deve ser revisto por um advogado.

## Assinatura de email

O ficheiro `assinatura-email-ats-studio.html` usa HTML compatível com clientes de email. Antes de usar, troca o dominio `https://atstudio.pt` e o email se ainda forem placeholders.

Para instalar, abre o ficheiro no browser, seleciona a assinatura visual, copia e cola no editor de assinatura do Gmail, Outlook ou Apple Mail.

## Nota sobre edicao

Os templates distinguem projetos sem CMS, com CMS e plataformas editaveis. Antes de enviar ao cliente, confirma qual e o modelo do projeto e remove texto que nao se aplica.
